About this tool

Find and fix broken variable references in your document. When variables are deleted, moved to different collections, or recreated, they lose their connection to elements. This tool helps you:

  • Scan all nodes for broken variable references
  • Find matching variables based on value and context
  • Manually rebind variables or auto-fix with high-confidence matches
  • View which nodes use specific variables
